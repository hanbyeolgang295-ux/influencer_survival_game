# Play Screen Backgrounds

Put play screen background images here. Supported extensions are:

- `.jpg`
- `.png`
- `.jpeg`
- `.webp`

## Main Event Backgrounds

Day 1 and day 6 main events can have separate backgrounds for each character.

Recommended folder layout:

- `main/sida_kim/day1.png`
- `main/sida_kim/day6.png`
- `main/jun_overclock/day1.png`
- `main/jun_overclock/day6.png`
- `main/dandelion_teacher/day1.png`
- `main/dandelion_teacher/day6.png`

This nested filename style is also supported:

- `main/sida_kim/sida_kim_day1.png`
- `main/sida_kim/sida_kim_day6.png`
- `main/jun_overclock/jun_overclock_day1.png`
- `main/jun_overclock/jun_overclock_day6.png`
- `main/dandelion_teacher/dandelion_teacher_day1.png`
- `main/dandelion_teacher/dandelion_teacher_day6.png`

Simple filename style is also supported:

- `main/sida_kim_day1.png`
- `main/sida_kim_day6.png`
- `main/jun_overclock_day1.png`
- `main/jun_overclock_day6.png`
- `main/dandelion_teacher_day1.png`
- `main/dandelion_teacher_day6.png`

Event id filenames also work:

- `main/sida_day1.png`
- `main/sida_day6.png`
- `main/jun_day1.png`
- `main/jun_day6.png`
- `main/dandelion_day1.png`
- `main/dandelion_day6.png`

## Character Default Backgrounds

If there is no day-specific main event background, the game falls back to the character background:

- `sida_kim_background.png`
- `jun_overclock_background.png`
- `dandelion_teacher_background.png`

If there is no character background, the game falls back to:

- `play_background.png`
